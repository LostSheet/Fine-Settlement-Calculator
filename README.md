# 벌금 정산 (Fine Settlement Calculator)

벌금을 적으면 **최소 송금 조합**과 우편 수수료까지 계산해 주는 정산기.
서버 없이 브라우저 안에서만 동작하는 단일 페이지 앱입니다.

- **메모장 모드** — 메모장에 `이름 금액`을 줄마다 적으면 표가 만들어집니다. 입력 단위(십만G·만G·1G) 선택.
- **카운터 모드** — 잡힘·죽음처럼 항목과 단가를 정해 두고, 칸을 눌러 셉니다(우클릭은 1회 빼기). 합계를 눌러 직접 수정, 즉석 벌금은 '기타'로.
- **프리셋** — 자주 오는 파티 명단을 저장해 두고, 한 번에 새 표를 시작합니다 (이름만 채우고 숫자·기록은 비움).
- **기록** — 카운터의 ＋·수정이 시각과 함께 한 줄씩 남고, 어떤 줄이든 역분개로 취소할 수 있습니다 (브라우저에만 저장).
- **지난 판** — 출발하거나 '처음부터'를 누르면 그때 판이 자동으로 보관됩니다. 읽기 전용, 최근 20판까지 (로컬 전용).
- **파티 모드** — 계정으로 로그인하면 대기실(로비)을 열어 파티원을 모으고, [출발]로 모인 인원 × 항목 구성의 새 판을 시작합니다.
  파티원은 자기 줄의 보통 항목만 눌러 **자수**하고(기록에 '자수'로 남습니다), 나머지는 읽기 전용입니다.
  장부의 진본은 방장 브라우저이고, 서버는 릴레이와 신원부 역할만 합니다. 비밀번호는 브라우저에서 선해시되어 원문이 서버에 가지 않습니다.
- **내 방송용 주소** — 계정마다 하나. OBS 브라우저 소스에 넣으면 지금 들어가 있는 파티의 벌금 현황이 방송에 뜹니다 (읽기 전용).
- 걷은 벌금을 인원수로 균등 분배하고, 송금 횟수가 이론적 최소가 되는 조합을 찾습니다 (비트마스크 DP).
- 우편 1홉이라 받는 쪽 전원이 정확히 (100−수수료)% 를 수령합니다.
- 공유: 표 전체가 담긴 URL(`#m=simple&d=도읍지25-…`), 인게임 채팅용 50자 요약, 디스코드용 송금 내역.
- 새로고침해도 표가 남습니다 (localStorage).
- **설치형(PWA)** — 주소창의 설치 아이콘을 누르면 브라우저 껍데기 없는 창으로 뜹니다.
  탭·주소창 없이 표만 남고, 인터넷이 끊겨도 열립니다.
  페이지는 항상 최신을 받아오고(네트워크 우선), 오프라인일 때만 캐시를 씁니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5175 — 저장 후 새로고침만 하면 반영
```

소스는 [src/GoldSettlement.jsx](src/GoldSettlement.jsx) 한 파일입니다.

## 빌드·배포

```bash
npm run build      # docs/ 로 빌드 (index.html 한 파일 + 매니페스트·서비스워커·아이콘)
node serve-docs.js # http://localhost:5180 — 설치·오프라인 동작을 실제로 확인할 때
```

아이콘은 [icon.js](icon.js) 가 빌드 때마다 그려서 만듭니다 (외부 도구 없음).

GitHub Pages 를 `main` 브랜치의 `/docs` 폴더로 설정하면 그대로 서빙됩니다.
`docs/index.html` 은 자기완결이라 아무 정적 호스트(Netlify·Cloudflare Pages 등)에 올려도 됩니다.
